# Значки и запуск с экрана «Домой»

Автоматические проверки: `swift test`, затем workflow AnderStore Build на macOS.
Следующие проверки требуют физического iPhone (минимум iOS 15 и актуальная iOS).

1. В обычном режиме нет верхних четырёх кнопок и Live Apps. Поиск, сетка,
   обновления и прогресс установки доступны. В меню — добавление значка и удаление.
2. Включить расширенные функции: проверить техническое меню и инструменты в
   настройках. Выключить: они снова скрыты; прежние настройки и данные сохранены.
3. Создать значок из меню и после установки приложения. Проверить инструкцию,
   загрузку без интернета, установку профиля, светлую/тёмную иконку, русские и
   английские подписи. Профиль содержит только web clip, без VPN/MDM-полей.
4. Отменить загрузку, повторить, подождать истечения восьми минут, загрузить снова.
   Закрытие инструкции останавливает сервер; через десять минут ссылка не работает.
5. Запустить значок при закрытом AnderStore, из магазина и настроек. Нужное
   приложение запускается сразу; при подготовке подписи появляется понятный статус.
6. Запустить из другого внутреннего приложения и вернуться в уже работающее.
   Обычное переключение не требует подтверждения; защита приложений сохраняется.
7. Быстро нажать один значок несколько раз, затем другой во время подготовки.
   Две операции одновременно не запускаются; повтор возможен после завершения.
8. Проверить выбранный контейнер, удалённый контейнер (подтверждение перехода на
   основные данные), удалённое приложение, отказ Face ID и ошибки подписи.
9. Проверить старые значки, приложения с JIT/многозадачностью, запуск после
   обновления приложения, возврат в AnderStore без повторного запуска.
10. На обоих языках проверить крупный текст и VoiceOver во всех новых экранах.

Успешная сборка и тесты не подтверждают физическую установку профиля или работу
частных API переключения приложений на конкретной версии iOS.
